# Internal Revenue Code

The Internal Revenue Code directs how LIFO may be used if necessary, stating that LIFO may only be used if the taxpayer establishes that they have no other way of valuing their inventory. ([[raw/FIFO and LIFO accounting#LIFO|§ LIFO]])
