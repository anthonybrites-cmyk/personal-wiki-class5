# Contingent Value Rights

Contingent Value Rights are rights granted by an acquirer to shareholders to facilitate transactions with inherent uncertainty. These rights can be event-driven or price-protection based, and they help bridge negotiations. Shareholders receive additional benefits if a specific event occurs within a timeframe.

## Key facts

- Contingent Value Rights are rights granted by an acquirer to a company’s shareholders, facilitating the transaction where some uncertainty is inherent. ([[raw/Contingent value rights|line 12]])
- Event-driven CVRs compensate owners for yet to eventuate positive developments in their business. ([[raw/Contingent value rights#Forms|§ Forms]])
- Price-protection CVRs are granted when payment is share based. ([[raw/Contingent value rights#Forms|§ Forms]])
- CVRs are common in the biotech and pharmaceutical industries. ([[raw/Contingent value rights#Forms|§ Forms]])
- The CVR then helps bridge this negotiation. ([[raw/Contingent value rights#Forms|§ Forms]])
- The CVR takes the form of a modified Asian option. ([[raw/Contingent value rights#Valuation|§ Valuation]])
