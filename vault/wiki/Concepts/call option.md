# call option

Contingent value rights (CVRs) are a form of option. ([[raw/Contingent value rights#Valuation|§ Valuation]]) They can be analogous to a call option where the payout is triggered by an event occurring and is zero otherwise. ([[raw/Contingent value rights#Valuation|§ Valuation]]) Alternatively, CVRs take the form of a modified Asian option. ([[raw/Contingent value rights#Valuation|§ Valuation]])

## Appears in

- [[Contingent Value Rights]] — The payout to the CVR holder is triggered by an event occurring, and will be zero otherwise
