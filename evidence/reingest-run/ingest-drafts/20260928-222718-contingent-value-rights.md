# Contingent Value Rights

Contingent Value Rights are rights granted by an acquirer to shareholders to facilitate transactions with inherent uncertainty. These rights can be event-driven or price-protection based, and they help bridge negotiations. Shareholders receive additional compensation if a specific event occurs within a timeframe.

## Key facts

- Event-driven CVRs compensate owners for positive developments in their business. ([[raw/Wikipedia - Contingent value rights#Forms|§ Forms]])
- Price-protection CVRs are granted when payment is share based. ([[raw/Wikipedia - Contingent value rights#Forms|§ Forms]])
- CVRs are common in the biotech and pharmaceutical industries. ([[raw/Wikipedia - Contingent value rights#Forms|§ Forms]])
- The payout to the CVR holder will be triggered by the event occurring and will be zero otherwise. ([[raw/Wikipedia - Contingent value rights#Valuation|§ Valuation]])
- Analysts apply a modified option pricing model based on the probability of the event, time horizon, and payout rules. ([[raw/Wikipedia - Contingent value rights#Valuation|§ Valuation]])

## Related notes

- [[Business Valuation]] — CVRs bridge a gap in how buyer and seller value the target; they are valued with a modified option pricing model
- [[Option Pricing]] — an event-driven CVR works like a call option, a price-protection CVR like a modified Asian option
- [[Intangible Asset]] — CVRs are common where value rests on uncertain intangible assets, as in biotech and pharma
